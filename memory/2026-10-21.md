### ⚠️ 三個關鍵教訓（下次 filter-repo 必做）
1. **必須先刪 `refs/original/*`** — filter-repo 會留備份 ref 把整個舊歷史掛回來。第一次漏了 → 跑完 gc 反而從 703M 迴彈到 943M
   ```bash
   git for-each-ref --format='%(refname)' refs/original/ | xargs -n1 git update-ref -d
   git reflog expire --expire=now --all && git gc --prune=now
   ```
2. **同一路徑在深層歷史有 3 種目錄名**（`08-Learning/02_AI-Research/` / `02-AI-Research/` / `02_AI-Research/`）→ 必須用 `git rev-list --objects --all | git cat-file --batch-check` 實查所有 blob，不能憑當前工作目錄結構猜
